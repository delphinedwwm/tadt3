# Trivi-All Dev Trek"# tadt3" 
Application web de quiz pour apprendre le développement web de manière ludique.

## 🎯 Fonctionnalités
- Système de quiz avec 60 questions catégorisées (HTML, CSS, JS, PHP, Laravel, SQL)
- 3 niveaux de difficulté (débutant, intermédiaire, confirmé)
- Authentification et gestion des rôles (admin/user)
- Panel administrateur : CRUD complet (users, rôles, questions & réponses, catégories)

## 🛠️ Stack technique
- **Back-end** : Laravel 11, PHP 8
- **Base de données** : MySQL (7 tables, relations complexes)
- **Front-end** : Blade Templates, JavaScript, Bootstrap
- **Sécurité** : Middlewares, CSRF protection, Spatie Permissions
- **Outils** : Laragon, VS Code, phpMyAdmin

## 📊 Architecture
- MVC strict
- Eloquent ORM
- Migrations + Seeders
- Listeners/Events (création auto de partie à l'inscription)

 ## 🎓 Compétences développées
- Architecture MVC Laravel
- Modélisation BDD relationnelle
- Système d'authentification et permissions
